# Mareas Watch Native V3 Dual

Un único APK para móvil Android y Wear OS.

## Funciones
- Detecta si se ejecuta en reloj o móvil y adapta la interfaz.
- GPS activo de alta precisión con pantalla "Buscando GPS...".
- Gráfica suave de marea estimada durante 24 horas.
- Marcador vertical y punto para la hora actual.
- Solo muestra la siguiente pleamar o bajamar estimada.
- Meteorología y oleaje reales desde Open-Meteo.
- Nombre de ubicación mediante Nominatim/OpenStreetMap.
- Icono propio de faro, luna y olas.

## Importante
La curva de marea continúa siendo una estimación matemática local. No procede de tablas oficiales y no debe usarse para navegación o seguridad.

## Compilar
1. Sube el contenido de esta carpeta a la raíz de un repositorio nuevo.
2. Ve a Actions > Generar APK V3 Dual > Run workflow.
3. Descarga el artefacto MareasWatchNativeV3Dual-APK.
4. Dentro encontrarás app-debug.apk.
